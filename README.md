## ადმინისტრატორის პირველი შესვლა

1. პროექტის მფლობელმა ლოკალურად გახსნას Git-ის მიერ გამოტოვებული `voltroar-admin-setup.txt` და დააკოპიროს კოდი.
2. გახსნას საიტის `/setup/` გვერდი. დარეზერვებულ ნომერზე აირჩიოს ახალი, სულ მცირე 12-სიმბოლოიანი პაროლი და ჩასვას ერთჯერადი კოდი.
3. შემდეგი შესვლები ჩვეულებრივი **Sign in** ფორმით ხდება. მხოლოდ ამ ანგარიშს ექნება **Admin** ბმული და სრული GPS წვდომა.

რეპოზიტორიაში ინახება შემთხვევითი კოდის მხოლოდ SHA-256 საკონტროლო მნიშვნელობა. ახალი გარემოსთვის მისი გადაფარვა შესაძლებელია Functions-ის `VOLTROAR_ADMIN_SETUP_DIGEST` გარემოს მნიშვნელობით, რომელიც მფლობელის მიერ შექმნილი მინიმუმ 32 შემთხვევითი ბაიტისგან მიღებული კოდის SHA-256 ჰეში უნდა იყოს.

## V8-ის გამოცდა

1. გაჩერებულ Tesla-ში გახსენი ძირითადი HTTPS მისამართი. **Engine sound**-ში აირჩიე სასურველი პრესეტი, შემდეგ აირჩიე **Manual Mode** და დააჭირე **Start Sound**. ხმები სინთეზირებულია. პრესეტებს შორის გადართვა დაკვრის დროსაც შეგიძლია.

## ლოკალურად გაშვება

1. გახსენი რეპოზიტორია VS Code-ში.
2. დააყენე Node.js 22 ან უფრო ახალი ვერსია.
3. VS Code-ის ტერმინალში გაუშვი:

```sh

npx netlify-cli dev --no-open
```

გახსენი Netlify Dev-ის მიერ ნაჩვენები მისამართი, ჩვეულებრივ [http://localhost:8888](http://localhost:8888). Netlify Dev ატარებს ფუნქციებს და ემულირებს საცავს. Windows PowerShell-ში შეგიძლია გამოიყენო `npm.cmd` და `npx.cmd`. [Netlify Dev](https://docs.netlify.com/api-and-cli-guides/cli-guides/manage-functions/)

სტატიკური ვერსიისა და შემოწმებების გაშვება:

```sh
npm test
npm run typecheck
npm run build
```

`npm run build` ქმნის `out/` საქაღალდეს. ანგარიშების სრული ტესტისთვის გამოიყენე Netlify Dev. მანქანიდან გასახსნელად გამოიყენე საჯარო HTTPS მისამართი.

## GPS დიაგნოსტიკა Tesla-ში

1. გაჩერებულ მანქანაში გახსენი **GPS Diagnostic**, დააჭირე **Start Test** და დაუშვი ლოკაციაზე წვდომა. ბრაუზერმა შეიძლება ცალკე მოითხოვოს მოძრაობის სენსორებზე წვდომა.
2. აიღე რამდენიმე ნიმუში გაჩერებულ მდგომარეობაში, შემდეგ კი ჩაატარე მოკლე მგზავრობის ტესტი მსუბუქი აჩქარებით, თანაბარი სიჩქარით და შენელებით. მოძრაობისას ეკრანს მხოლოდ მგზავრი მართავს. თუ ნებართვა უარყოფილია, შეცვალე საიტის ლოკაციის პარამეტრი და დაიწყე ახალი სესია.
3. დააჭირე **Stop Test**, შემდეგ **Photo Report**. ეკრანზე გამოჩნდება GPS-ის, სიჩქარის, სენსორებისა და აუდიოს შეჯამება. ტელეფონით გადაუღე ფოტო მთლიან ანგარიშს და ჩატში მიამაგრე. იმავე მისამართზე დაბრუნებისას **Last Photo Report** გახსნის ბოლოს შენახულ ანგარიშს, თუ ბრაუზერის მეხსიერება ხელმისაწვდომია.

**Export JSON** შეგიძლია გამოიყენო ყველა ნიმუშისა და მოვლენის ჩამოსატვირთად. **Photo Report**-ში `p95` აღნიშნავს მნიშვნელობას, რომლის ტოლი ან ნაკლებია გაზომვების სულ მცირე 95%. callback-ის წყვეტების რაოდენობაში შედის დასრულებულ განახლებებს შორის გრძელი შუალედები და ბოლო განახლებიდან ტესტის გაჩერებამდე არსებული გრძელი შუალედი.
