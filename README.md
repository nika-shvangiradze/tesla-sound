# VoltSound GPS Diagnostic v1.0

Tesla Model 3-ის ჰორიზონტალური ეკრანისთვის შექმნილი დიაგნოსტიკა. აპი იყენებს Next.js App Router-ს, TypeScript-სა და Tailwind CSS-ს. მონაცემებს პირდაპირ ბრაუზერის API-ებიდან იღებს. სესია ბრაუზერის მეხსიერებაში ინახება და მონაცემთა გასაგზავნად სერვერს არ იყენებს. აპს ანგარიში, გამოწერა ან ფასიანი API არ სჭირდება.

## ლოკალურად გაშვება

1. ამოარქივე პროექტის ZIP და გახსენი საქაღალდე VS Code-ში.
2. დააყენე Node.js 22 ან უფრო ახალი ვერსია.
3. VS Code-ის ტერმინალში გაუშვი:

```sh
npm ci
npm run dev
```

გახსენი [http://localhost:3000](http://localhost:3000). Windows PowerShell-ში, თუ `npm.ps1` დაბლოკილია, იმავე ბრძანებებში გამოიყენე `npm.cmd`.

სტატიკური ვერსიისა და შემოწმებების გაშვება:

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`npm run build` ქმნის `out/` საქაღალდეს. `npm run preview` მას ემსახურება [localhost:3000](http://localhost:3000)-ზე. ჯერ გააჩერე dev სერვერი, თუ ის იმავე პორტზე მუშაობს. `localhost` დეველოპერის კომპიუტერზე უსაფრთხო კონტექსტად ითვლება. მანქანიდან გასახსნელად გამოიყენე საჯარო HTTPS მისამართი. [Next.js-ის სტატიკური ექსპორტი](https://nextjs.org/docs/app/guides/static-exports)

## განთავსება უფასო HTTPS ჰოსტინგზე

1. გაუშვი `npm ci` და `npm run build`, ან ამოარქივე ცალკე მოწოდებული სტატიკური ZIP.
2. შედი [Netlify Drop-ში](https://app.netlify.com/drop) და ატვირთე მზა საქაღალდე, რომლის უშუალო შიგთავსშია `index.html`, `audio-probe.js` და `_next/`. ლოკალური ბილდის შემთხვევაში ესაა `out/`.
3. თუ პროექტს წვდომის შეზღუდვა აქვს, შეცვალე მისი ხილვადობა ისე, რომ Tesla-ს ბრაუზერმა გვერდი ავტორიზაციის გარეშე გახსნას. მანქანის ბრაუზერში გახსენი Netlify-ის მინიჭებული `https://….netlify.app` მისამართი. [ატვირთვის ინსტრუქცია](https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/) · [HTTPS](https://docs.netlify.com/manage/domains/secure-domains-with-https/https-ssl/)

აპს გამოყენების საკუთარი კვოტა არ აქვს. Netlify-ის უფასო გეგმაზე ჰოსტინგს თვიური კრედიტების ლიმიტი აქვს. [Netlify-ის გეგმები](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/credit-based-pricing-plans/)

## ტესტი Tesla-ში

1. გაჩერებულ მანქანაში გახსენი HTTPS მისამართი, დააჭირე **Start Test** და დაუშვი ლოკაციაზე წვდომა. ბრაუზერმა შეიძლება ცალკე მოითხოვოს მოძრაობის სენსორებზე წვდომა.
2. აიღე რამდენიმე ნიმუში გაჩერებულ მდგომარეობაში, შემდეგ კი ჩაატარე მოკლე მგზავრობის ტესტი მსუბუქი აჩქარებით, თანაბარი სიჩქარით და შენელებით. მოძრაობისას ეკრანს მხოლოდ მგზავრი მართავს. თუ ნებართვა უარყოფილია, შეცვალე საიტის ლოკაციის პარამეტრი და დაიწყე ახალი სესია.
3. დააჭირე **Stop Test**, შემდეგ **Export JSON**. თუ ბრაუზერი ჩამოტვირთვას არ უჭერს მხარს, გახსენი **View exported JSON** და დააკოპირე ტექსტი, თუ ბრაუზერში კოპირება ხელმისაწვდომია. გაშვებულ სესიაშიც შეგიძლია ექსპორტი. ყოველი ახალი ტესტი წინა სესიას ჩაანაცვლებს. გვერდის დახურვამდე შეინახე საჭირო შედეგი.

## შედეგების წაკითხვა

| ველი | რას ზომავს |
| --- | --- |
| `speedKmh` | `coords.speed × 3.6`. `null` ნიშნავს, რომ ბრაუზერს ამ ნიმუშში სიჩქარე არ მოუცია. 0 რეალური ნულოვანი მნიშვნელობაა. |
| `callbackIntervalMs` | ზედიზედ ორი წარმატებული callback-ის შუალედი მონოტონური საათით. |
| `positionIntervalMs` | ზედიზედ ორი პოზიციის timestamp-ის სხვაობა. 0 ნიშნავს, რომ timestamp განმეორდა. |
| `dataAgeMs` | callback-ის მიღების Unix timestamp-ს გამოკლებული პოზიციის timestamp. უარყოფითი მნიშვნელობა ინახება საათების შეუსაბამობის გამოსავლენად. ეს მეტრიკა არ ზომავს პედლიდან დინამიკამდე დაყოვნებას. |
| `accuracyM` | ბრაუზერის შეფასებული ჰორიზონტალური პოზიციის სიზუსტე მეტრებში. |
| `events` | შეცდომები, სიგნალის დაკარგვა და აღდგენა, გვერდის ხილვადობის ცვლილებები და სენსორების შემოწმების შედეგები. |

Watchdog აჩვენებს **Signal lost**, თუ პირველ პოზიციას 12 წამში ვერ იღებს, ბოლო callback-იდან 5 წამი გადის, ან ბოლო პოზიციის timestamp მინიმუმ 5 წამისაა. მიღებული პოზიციის შემდეგ `POSITION_UNAVAILABLE` ასევე აჩვენებს დაკარგულ სიგნალს. ეს დაკვირვებაა ბრაუზერის მონაცემთა ნაკადზე. გაჩერებულ ან ფონურ გვერდზე ბრაუზერს შეუძლია განახლებები შეაყოვნოს. ნებართვის უარყოფა ცალკე ჩანს და GPS-ის მონიტორინგი წყდება. [Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API/Using_the_Geolocation_API)

**Available** ნიშნავს API-ის აღმოჩენას. **Verified** ნიშნავს, რომ Geolocation-მა პოზიცია დააბრუნა, DeviceMotion-მა რიცხვითი აჩქარება მოგვაწოდა, AudioContext გადავიდა `running` მდგომარეობაში, ან AudioWorklet-მა უხმო აუდიოკადრი დაამუშავა. **No data** DeviceMotion-ზე ნიშნავს, რომ 6 წამში აჩქარების ვერცერთი კომპონენტი ვერ მივიღეთ. თუ მონაცემი მოგვიანებით მოვიდა, სტატუსი განახლდება. AudioContext-ის დაყოვნებები ბრაუზერის შეფასებებია. უხმო შემოწმება დინამიკებიდან გამოსულ ხმას არ ზომავს. [DeviceMotion-ის ნებართვა](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static) · [AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Using_AudioWorklet)

JSON-ში შედის მიმდინარე სესიის ყველა GPS ნიმუში, მოვლენები, ბოლო აჩქარების ვექტორები, აჩქარების მოვლენების რაოდენობა, აუდიოს შედეგები და ბრაუზერის user agent. გრძედი და განედი ანგარიშში არ ინახება.

VoltSound V8 GPS Edition-ის დასაგეგმად შეინახე მოძრაობისას მიღებული JSON. მის მიხედვით შეფასდება callback-ების სიხშირე, timestamp-ის ასაკი, სიჩქარის ხელმისაწვდომობა და აჩქარების სენსორის სარგებლიანობა. Tesla-ს კონკრეტულ ბრაუზერში მუშაობა მანქანაში ჩატარებული ტესტით უნდა დადასტურდეს.
