## GPS Drive-ის პაკეტები

მომხმარებელი რეგისტრირდება ტელეფონითა და პაროლით. ქართული მობილურის ნომერი იწერება ცხრა ციფრით, `+995`-ისა და გამოტოვებების გარეშე, მაგალითად `555555555`. **Change password** ითხოვს მიმდინარე და ახალ პაროლებს. შეცვლის შემდეგ სხვა სესიები იხურება. რეგისტრაციის შემდეგ ხელმისაწვდომია Manual Mode და GPS Diagnostic. GPS Drive-ის პაკეტებია **1 თვე — ₾5**, **3 თვე — ₾12**, **6 თვე — ₾25**, **1 წელი — ₾50**.

მომხმარებელი ირჩევს პაკეტს და წერს WhatsApp-ში, Viber-ში ან Telegram-ში ნომერზე **+995 551 099 081**. WhatsApp-სა და Telegram-ში ტექსტი წინასწარ ივსება პაკეტითა და ანგარიშის ნომრით. Viber-ისთვის ტექსტი შეიძლება **გამზადებული შეტყობინებიდან** დაკოპირდეს. გადარიცხვის შემოწმების შემდეგ ადმინი **Admin → User accounts** განყოფილებაში პოულობს მომხმარებელს და აჭერს **Activate**. **Extend** მოქმედ ვადას უმატებს არჩეულ პერიოდს. **Turn off GPS Drive** აუქმებს პაკეტს და ანგარიშს ტოვებს ხელმისაწვდომად. **Delete user** შლის ანგარიშის პაროლის ჰეშს, პაკეტსა და სესიებს და მომხმარებელს სიიდან აქრობს. იმავე ნომრით ხელახლა რეგისტრაცია შეიძლება. ვადის ამოწურვისას GPS Drive ავტომატურად იკეტება.

რეგისტრაციისას SMS არ იგზავნება. პაკეტის აქტივაციისთვის ადმინი იყენებს დადასტურებული გადარიცხვისა და შეტყობინებაში მითითებული VoltRoar-ის ანგარიშის ნომერს.

## ადმინისტრატორის პირველი შესვლა

1. პროექტის მფლობელმა ლოკალურად გახსნას Git-ის მიერ გამოტოვებული `voltroar-admin-setup.txt` და დააკოპიროს კოდი.
2. გახსნას საიტის `/setup/` გვერდი. დარეზერვებულ ნომერზე აირჩიოს ახალი, სულ მცირე 12-სიმბოლოიანი პაროლი და ჩასვას ერთჯერადი კოდი.
3. შემდეგი შესვლები ჩვეულებრივი **Sign in** ფორმით ხდება. მხოლოდ ამ ანგარიშს ექნება **Admin** ბმული და სრული GPS წვდომა.

რეპოზიტორიაში ინახება შემთხვევითი კოდის მხოლოდ SHA-256 საკონტროლო მნიშვნელობა. ახალი გარემოსთვის მისი გადაფარვა შესაძლებელია Functions-ის `VOLTROAR_ADMIN_SETUP_DIGEST` გარემოს მნიშვნელობით, რომელიც მფლობელის მიერ შექმნილი მინიმუმ 32 შემთხვევითი ბაიტისგან მიღებული კოდის SHA-256 ჰეში უნდა იყოს.

## V8-ის გამოცდა

1. გაჩერებულ Tesla-ში გახსენი ძირითადი HTTPS მისამართი. **Engine sound**-ში აირჩიე სასურველი პრესეტი, შემდეგ აირჩიე **Manual Mode** და დააჭირე **Start Sound**. ხმები სინთეზირებულია. პრესეტებს შორის გადართვა დაკვრის დროსაც შეგიძლია.
2. შეცვალე **Target RPM** ან დააჭირე **Rev**. ხმამაღლობას **Volume**-ით მართავ, დაკვრას კი **Stop Sound** აჩერებს.
3. GPS-ისთვის აირჩიე **GPS Drive**, დაუშვი ლოკაციაზე წვდომა და მგზავრობისას დააკვირდი RPM-სა და ვირტუალურ გადაცემას. მოძრაობისას ეკრანს მხოლოდ მგზავრი მართავს. დიაგნოსტიკა ხელმისაწვდომია **GPS Diagnostic** ბმულით ან `/diagnostic/` მისამართზე.

GPS რეჟიმში სპიდომეტრი ბრაუზერის გაზომილ სიჩქარეს აჩვენებს, მათ შორის მაშინაც, როცა ხმა გამორთულია. თითოეულ პრესეტს თავისი კოლოფი და სიჩქარის ერთეული აქვს. ბრუნისა და გადაცემის გამოსათვლელად აპი იყენებს სიჩქარეს, საბურავის გარშემოწერილობას, გადაცემის ფარდობასა და მთავარ გადაცემას. აჩქარების მაქსიმუმ 330 მწმ პროგნოზი მხოლოდ სიმულაციაზე მოქმედებს. გადართვების ზღვრები, გადაბმულობის სრიალი და ბრუნის გათანაბრება სიმულაციის ნაწილია. უკუსვლა GPS სიჩქარიდან არ გამოითვლება. ხელით ბრუნის მართვისას ძრავა თავისუფლად ბრუნავს ნეიტრალში.

გაზომილი 0 სიჩქარე ჩანს როგორც 0. ახალი გამოსადეგი ნიმუშის გარეშე 1.25 წამის შემდეგ სიჩქარისა და გადაცემის წაკითხვა ქრება და ბრუნი უქმ სვლას უბრუნდება. მექანიკური კოლოფისთვისაც GPS რეჟიმში გადართვები ავტომატურად გამოითვლება. გვერდის ჩაკეცვისას ჩართული ხმა მუშაობს, თუ ბრაუზერი ფონურ აუდიოს უშვებს. თუ ბრაუზერმა ხმა დროებით შეაჩერა, აპი დაკვრის გაგრძელებას ცდილობს, მათ შორის გვერდზე დაბრუნებისას.

ნაგულისხმევად ხმა იკვრება Web Audio-თი. **Try AudioWorklet** ჩართე ხმის გაშვებამდე, თუ ამ გზის გამოცდა გინდა. ჩატვირთვის ან დამუშავების შეცდომის დროს დაკვრა სტანდარტულ Web Audio-ზე გადადის. პედლიდან დინამიკამდე რეალური დაყოვნება მანქანაში უნდა გაიზომოს.

## ლოკალურად გაშვება

1. გახსენი რეპოზიტორია VS Code-ში.
2. დააყენე Node.js 22 ან უფრო ახალი ვერსია.
3. VS Code-ის ტერმინალში გაუშვი:

```sh
npm ci
npx netlify-cli dev --no-open
```

გახსენი Netlify Dev-ის მიერ ნაჩვენები მისამართი, ჩვეულებრივ [http://localhost:8888](http://localhost:8888). Netlify Dev ატარებს ფუნქციებს და ემულირებს საცავს. Windows PowerShell-ში შეგიძლია გამოიყენო `npm.cmd` და `npx.cmd`. [Netlify Dev](https://docs.netlify.com/api-and-cli-guides/cli-guides/manage-functions/)

სტატიკური ვერსიისა და შემოწმებების გაშვება:

```sh
npm test
npm run typecheck
npm run build
```

`npm run build` ქმნის `out/` საქაღალდეს. ანგარიშების სრული ტესტისთვის გამოიყენე Netlify Dev. მანქანიდან გასახსნელად გამოიყენე საჯარო HTTPS მისამართი.

## GPS დიაგნოსტიკა Tesla-ში

1. გაჩერებულ მანქანაში გახსენი **GPS Diagnostic**, დააჭირე **Start Test** და დაუშვი ლოკაციაზე წვდომა. ბრაუზერმა შეიძლება ცალკე მოითხოვოს მოძრაობის სენსორებზე წვდომა.
2. აიღე რამდენიმე ნიმუში გაჩერებულ მდგომარეობაში, შემდეგ კი ჩაატარე მოკლე მგზავრობის ტესტი მსუბუქი აჩქარებით, თანაბარი სიჩქარით და შენელებით. მოძრაობისას ეკრანს მხოლოდ მგზავრი მართავს. თუ ნებართვა უარყოფილია, შეცვალე საიტის ლოკაციის პარამეტრი და დაიწყე ახალი სესია.
3. დააჭირე **Stop Test**, შემდეგ **Photo Report**. ეკრანზე გამოჩნდება GPS-ის, სიჩქარის, სენსორებისა და აუდიოს შეჯამება. ტელეფონით გადაუღე ფოტო მთლიან ანგარიშს და ჩატში მიამაგრე. იმავე მისამართზე დაბრუნებისას **Last Photo Report** გახსნის ბოლოს შენახულ ანგარიშს, თუ ბრაუზერის მეხსიერება ხელმისაწვდომია.

**Export JSON** შეგიძლია გამოიყენო ყველა ნიმუშისა და მოვლენის ჩამოსატვირთად. **Photo Report**-ში `p95` აღნიშნავს მნიშვნელობას, რომლის ტოლი ან ნაკლებია გაზომვების სულ მცირე 95%. callback-ის წყვეტების რაოდენობაში შედის დასრულებულ განახლებებს შორის გრძელი შუალედები და ბოლო განახლებიდან ტესტის გაჩერებამდე არსებული გრძელი შუალედი.

[Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API/Using_the_Geolocation_API)
